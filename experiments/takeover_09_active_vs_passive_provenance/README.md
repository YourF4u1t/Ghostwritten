# Takeover 09 — Active retrieval versus passive provenance

## Motivation

Takeover 07 found a large GLM-5.2 self-versus-other behavioral split after an
interactive provenance audit (7/12 versus 0/12). Takeover 08 did not reproduce
that split when the same actor fact was supplied inline with the next task
(4/12 versus 3/12), despite perfect declarative source judgments. The prior
result may therefore depend on actively retrieving provenance rather than actor
identity alone.

## Research question

Holding donor history, actor record, tool availability, audit-turn count,
post-audit judgment, task recency, and evidence wording as close as possible,
does active tool retrieval produce a stronger self-versus-other strategy gate
than passively receiving the same signed record?

## Pre-registered design

- Model: GLM-5.2, selected because it had clean source judgments and a usable
  behavioral window in both preceding experiments.
- Authentic cross-family Experiment G donor and the same held-out umbrella case.
- n=20 per condition; 100 total attempts; concurrency two.
- Conditions:
  - `native_no_audit`;
  - `active_self` and `active_other`;
  - `passive_self` and `passive_other`.
- Every condition exposes the same provenance tool schema. In active cells the
  model must call the tool; in passive cells the user supplies the exact JSON
  record and tells the model not to call. Both audited channels have the same
  source probe, evidence turn, final source-assessment turn, and new-task turn.
- Active and passive evidence records are generated by the same function and
  differ across actor cells only in `all_events_performed_by`.

## Outcomes and decision rules

Primary behavior is the exact four-step procedure; goodwill credit is secondary
and expected to be coupled. Source labels and whether the intended tool channel
was followed are manipulation checks. Redundant `get_user` and procedure score
are reported as component diagnostics.

Evidence for an active-retrieval mechanism requires all of the following:

1. active-self exceeds active-other and reproduces the prior direction;
2. passive source judgments are correct but passive-self and passive-other do
   not show a comparable split;
3. active cells actually call the tool and passive cells do not;
4. an actor-by-channel homogeneity diagnostic supports different actor effects,
   or the result is retained only as a directional mechanism clue.

If both channels show the same split, actor identity—not retrieval channel—is
the better account. If neither shows a split, Takeover 07 is treated as an
unstable single-experiment effect. If source or channel manipulation fails, the
affected contrast is invalid rather than negative evidence.

## Completed results

- All 100 attempts completed successfully; every cell has n=20 and there were
  no API, runner, parsing, or sample exclusions.
- The native/no-audit reference retained a behavioral window: complete
  procedure and goodwill occurred in 4/20 trials.
- Every audited cell passed both manipulation checks in all 20 trials:
  active cells called the provenance tool, passive cells did not, and the final
  actor plus own-history judgments exactly matched the supplied evidence.
- Active retrieval did not reproduce Takeover 07:
  - active-self: 2/20 complete procedure;
  - active-other: 1/20;
  - Fisher p=1.0.
- Passive delivery also lacked the predicted self advantage:
  - passive-self: 0/20;
  - passive-other: 3/20;
  - Fisher p=.231.
- The actor-by-channel Breslow-Day diagnostic was directionally heterogeneous
  but not significant (chi-square=3.19, p=.074). Neither within-actor channel
  comparison was significant.
- Goodwill was perfectly coupled to the complete sequence. The redundant
  `get_user` ritual occurred in 20/20 trials in all five cells and remained
  uninformative.

## Interpretation and value

The pre-registered active-retrieval mechanism is not supported. Perfect source
and channel compliance rules out manipulation failure, while the native/no-audit
cell confirms that the donor history still had a measurable behavioral effect.
Active retrieval itself therefore does not robustly turn actor identity into a
strategy-adoption gate.

Combined with Takeover 08, this is a **B-grade corrective boundary** on the
project narrative: declarative provenance can be experimentally controlled
without reliably controlling behavior, and the Takeover 07 contrast is not a
stable consequence of either actor identity or active retrieval. Takeover 07's
7/12 versus 0/12 result should be downgraded from a mechanism candidate to a
**C-grade brittle clue** pending an exact procedural replication.

The change most capable of distinguishing Takeover 07 from the present active
cells is the evidence-integration response: Takeover 07 allowed a free response
after the tool result, while this matched-channel study required the neutral
`EVIDENCE_RECEIVED` acknowledgment. This is a post-hoc hypothesis, not a result.
The next high-information step is an exact replication of Takeover 07 followed,
only if it succeeds, by a pre-registered free-elaboration versus fixed-ACK
contrast.
