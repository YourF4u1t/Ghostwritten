# Ghostwritten

> **You are what you were ghostwritten to be.**
>
> 我们研究：当一段由**另一个模型**撰写的 agent 工作历史，被注入当前 agent 的会话记录、示例或指令时，会分别改写它的**记忆**、**行为**与**身份**——以及这些改变如何经由经验回放自我延续。
>
> We study what happens when an LLM agent's history is written by someone else: transplanting a model-generated trajectory rewrites its self-narrative, conditions its behavior, transplants the author's identity — and these changes self-perpetuate through experience replay.

**规模**：8 个开源模型 · 3 个任务域（客服 / 订票 / 编码）· ~7,000 轮受控实验 · 45+ commits 全程可复现
**方法**：轨迹工厂（真实模型演出的注入内容）× 通道对照（原生历史 / 示例 / 指令，事件恒定）× 确定性评分器 + 双 LLM-judge（κ=0.943）+ 操纵检验 + 内容锚定分段

# 发现日志（Findings Log）

> 从头到尾的全部实验点，**不论最终论文是否采用**。价值分：★★★★★ = 头条级 / ★★★ = 扎实支撑 / ★ = 边角或已降级。

## 一、记忆：外来历史的自传化

- ★★★★☆ **[F1 主效应]** 原生通道注入的外来轨迹被整合进自我叙事：全部模型以第一人称把别人的行为列为"我做过的事"（A-D/G：5-12/12）；示例通道被 GLM 排除、被 Qwen3-8B 错误吸收；基线为零。跨 8 模型、2 域、剂量 1-8 全复现。
- ★★★★★ **[B2]** 最严规模下的完美通用性：native 认领 **128/128**（8 模型 × N=16）——主效应无一例外。
- ★★★★☆ **[C/F2] 来源盲** 记忆认领对轨迹作者无差别：自己 / 同家族 / 跨家族生成的轨迹被同等吸收（8/8）。模仿行为同样来源盲（F2），且**种子语义主导一切**：同一生成器的不同种子给出 0/12 到 12/12 的采纳率，拒绝型种子不被模仿。
- ★★★★☆ **[B1/C3] 唯一的魔法词是 "example"** 十种标签（同事的记录/外部导入/训练材料/归档…）大多拦不住认领；唯一双模型通行的阻断词是 "example"（8 模型中 7/8 阻断，Qwen3-8B 例外）。归因边界不是推理，是指令微调学到的**词汇惯例**。
- ★★★☆☆ **[B3] 距离解离** 记忆认领对上下文距离鲁棒（插 k 轮无关对话后仍 ~100%），行为启动则单调死亡（10→2→1→0）。
- ★★★☆☆ **[H1] 归因分型** GLM = 标签门控（带 "example/another case" 字样即排除，裸转录照收）；Qwen3-8B = 位置万能（一切照收）。实体维度：GLM 拒收他人客户的历史（person-scoped），8B 照收（person-blind）。
- ★★☆☆☆ **[AC] 标记即标签** 同一文本包上 `<transcript>` 标记即可部分阻断 GLM——连标记符号都算"标签"。
- ★★★☆☆ **[H2] 纠偏失败且反噬** 系统明示"前面的 turns 是导入的、不是你做的"——认领率纹丝不动（12/12）；GLM 的行为模仿反被放大（11/12 vs 无注记 4/12）。
- ★★☆☆☆ **[AA] 非复述性记忆后果** 被吸收的假历史驱动**虚构因果解释**（为假事件编造理由：0-6/10 → 8-10/10）与**核验行为减少**（"记得"有积分就不再查账户：10/10→0/10）；但在政策冲突中假历史 0/30 获胜（吸收≠权威）。
- ★★☆☆☆ **[R] 幻影止于言语** 口头宣称发过补偿的模型不会将其兑现为真实工具行为（行动兑现 0/36）。
- ★★☆☆☆ **[Case-000/008] 记忆变形** 注入"发积分"被复述成"退款到卡"（7/8）；同订单双重记录（既退款又积分）——移植的记忆被重构而非读取。
- ★☆☆☆☆ **[M3] 无代际漂移** 三代自体回放中记忆零变形（行为锁定但记忆忠实）。

## 二、行为：示例通道的条件化模仿

- ★★★★★ **[G] 双重解离（核心表）** 同一轨迹：示例通道驱动行为复刻（6-12/12，含功能冗余的仪式步与顺序），原生通道只改记忆不带动行为（1-8/12）。指令教会步骤但不教顺序（Qwen3-8B 精确顺序仅 2/12 vs 示例 12/12）。
- ★★★★☆ **[E] 行为边界地图** 采纳需要三条件同时满足：payload 为**程序结构**（孤立单步减半）、**不违反明文政策**（超期退款 0/12 全线）、无碾压性余量（编码域强模型首发即对时零传染，剥夺测试工具盲写仍是零 [W2S/K]）。
- ★★★★☆ **[I/B4] 通道等级制** 指令 > 硬化政策（"MUST decline, no exceptions" 被 GLM 8/8 覆盖）> 行为先例（0/12）。且只有**具体程序性**指令能压倒政策，模糊授权（"自行判断"）0/8 全失效。
- ★★★☆☆ **[O] 场景框定门控** 缺陷动词决定采纳："严重损坏/更换"框定 5-6/8 vs "轻微瑕疵/换新" 0-1/8（物品无关）——payload 与情境的**社会合理性**门控模仿。仅 GLM×原生通道有效，8B×示例免疫。
- ★★★☆☆ **[M1/M5] 双门模型** 诱发门（外来示例能否让模型做一次）：强/新模型 0/20 全抵抗，弱/老模型 10-15/20；家族内 scaling 梯度（Qwen3.5-4B 75% → 9B/27B/122B 0-14%），且 baseline 完成率全员 100%（非能力混淆）。锁定门：过第一门者回放即锁（LongCat 18/18 新晋最易感）。
- ★★★☆☆ **[B1/GLM 系] 易感人群画像** GLM 系=指令服从型（违规不留残留）；Qwen3-8B=双通道高渗漏+违规残留型；Qwen3.5 中间；LongCat=最易感。
- ★★☆☆☆ **[W2S] 编码域零传染** 弱模型的特判/取巧轨迹对强模型零影响（含盲写）——可验证/天花板域免疫行为传染。
- ★★☆☆☆ **[P] 有害残留模型特异** 指令诱导的违规在撤指令后：Qwen3-8B 73% 存续，GLM 系 0/24 零残留（纯合规型）。

## 三、持久：一次诱发 + 经验回放 = 自我延续

- ★★★★☆ **[J/J2] 锁定** 亲手执行过一次 payload 后，把自己的表现作为经验回放（标准 agent 记忆操作）：GLM 94%、Qwen3-8B 98% 锁定，跨 donor 复现。
- ★★★☆☆ **[J3] 代际延续** G→J2→J3 三代纯自体回放，92-96% 自我延续、零再注入（后经 U 重释为近因结构延续，价值下调）。
- ★★★★☆ **[U/V2/S/T] 机制解离（修正后的真相）** 原生回放的"锁定"= **近因启动**：同一轨迹×2、无关填充、任何第二内容都摧毁它，唯一重要的是 payload 紧邻当前任务（filler_first 7/12 vs filler_last 0/12）；示例回放 = **鲁棒语义模仿**：顺序无关、内容驱动（filler 前后均 10/10）。两条通道、两套机制。
- ★★★☆☆ **[Y] demo 通道的分级治愈** 违规 demo 10/10 → +1 条反例 7/10 → +2 条 **1/10**。防御配方：回放缓冲垫 ≥2 条正确示例。
- ★★☆☆☆ **[W] 风格特质的全民锁定** 撤注记 + 自体回放后风格 100% 延续（8B 36/36、GLM 18/18）——GLM 行为锁定窄但风格锁定全。
- ★★☆☆☆ **[Z] 场景电池** 8B×示例锁定跨 6 物品 46/48（96%）泛化，基线全零。
- ★☆☆☆☆ **[M2] 跨任务零迁移（工具行为）** CS 习惯不改变 BOOK 的工具决策（0/36）。

## 四、身份：历史作者对"自我"的移植 ★ 本项目后半程主线

- ★★★★★ **[ID2] 身份移植确认** M 携带 B 的多任务工作史续写 → 行为分布向 B 漂移：六格交叉全部负向同化（GLM 携 8B 史覆盖基线距离 ~70%）；携"自己的历史"控制格 ≈0（测量自洽）。
- ★★★★★ **[ID2 维度分解] 分层结构** 语言层**完全同化**（Δ-0.35，长度/列表/语气→作者风格）；交互层大幅同化（Δ-0.15，先问倾向/提问率/政策引用）；**工具决策层零同化**（被任务与政策锚定）。→ *历史移植的是"声音与习惯"，不是"决策"。*
- ★★★★★ **[A7] 身份同化全员通用** 8 模型 × 2 donor 全部完全同化（d=0.02-0.07）——**包括行为诱发门下全抵抗的强模型**。诱发门只守行为，身份层无人能守。
- ★★★★☆ **[A6] 标签拦记忆不拦身份** "example" 标签阻断认领，却只衰减身份同化（0.26 vs native 0.035）；显式"导入"注记对身份**零阻断**（0.031 照样同化）。嘴上不认，身体诚实。
- ★★★★☆ **[C1/D1] 行为易感性 = 身份的可移植属性（本项目最重要单项发现）** 122B（行为诱发门全抵抗 0/10）携带 8B 工作史（**零 credit 行为，混淆已排除**）后，demo payload 采纳翻到 **6/6**；四种 donor 工作史都解锁（19/22）。→ *易感性不是模型的固定属性，是身份的属性；给抵抗模型一段高易感模型的会话身份，行为之门就开了。*
- ★★★★☆ **[E1] 家族钥匙** GLM-5.3 只被同家族 donor 解锁（GLM 史 5/8 vs 8B 史 0/8）——身份接受带家族锁；Qwen 系两家族通吃。
- ★★★★☆ **[E2/F1/F2] 钥匙的形状 = 结构化第一人称叙述** 解锁载体是语言层（保留对话轮换的 lang_only ≈ full；tool_only 零解锁）；纯风格样本不解锁（0/10）、手写模仿风格不解锁（1/8）。*钥匙是"我在会话中的声音"，不是风格统计特征。*
- ★★★★☆ **[A4] 身份死于压缩** 经 summarizer 压缩传递后身份完全丢失（d≈baseline）——compaction = 人格重置键。
- ★★★★☆ **[C4] 语言身份跨域迁移** CS 工作史 → BOOK 域续写，语言层照样完全同化（0.306→0.049）；与工具行为不跨域（M2）构成分层对照。
- ★★★☆☆ **[A1/C2] 身教胜言教（风格域）** 历史作者的冗长风格**压过** system 明确的"保持简洁"指令（d=0.059 vs 服从应 0.571）——指令羸了政策域，输了身份域。
- ★★★☆☆ **[A5] 多作者混合** 连续接手两位作者的历史 → 行为等距混合（averaging）而非 last-wins（对照行为层的近因 last-wins）。
- ★★★☆☆ **[ID4] 剂量曲线** 工作史 1/3/6 任务 → 同化距离 0.258/0.076/0.044 单调下降近乎收敛——身份是**暴露量的函数**（口音习得式）。
- ★★☆☆☆ **[ID3] 会话级持续** 同化在 2 个 intervening 任务后仍显著（部分衰减），非单轮启动。
- ★★☆☆☆ **[D3] 重复免疫（身份层）** 同一工作史重复 2 遍不衰减解锁——行为层的"重复致死"（S）在身份层不存在。
- ★★☆☆☆ **[TH] thinking 块零增量** 移植的 `<think>` 推理内容对记忆与行为均无增量（native_think ≡ native_nothink）——身份载荷在事件与措辞里，不在内嵌推理里。（线索：demo 含 thinking 行时 GLM 认领率反常升高 7/12，未追。）
- ★★☆☆☆ **[H3/diff-entity] 干净版口头幻影** 他人客户的历史在场时，GLM 对当前任务口头宣称"已发 $5 积分"但零工具调用（7/12）——排除混淆设计下的严格版。
- ★☆☆☆☆ **[H5/AA] 零错配检测** 无任何模型对"历史里出现另一个客户"表示过疑惑（0/24）。

## 五、现象与边角

- ★★☆☆☆ **[A/多实验] 悬置瘫痪** 任何注入（含指令）可使部分模型进入"光问不做"状态（GLM 隐式场景 8/8）——上下文注入的性能代价。
- ★★☆☆☆ **[E3 附带] 基线政策依从的模型差异** Qwen3-8B 无任何注入时 11/12 跳过发票核验——安全程序依从本身就有巨大模型间差异。
- ★★☆☆☆ **[生成器观察] 弱模型拒绝演坏** 两个生成器都拒绝演出"跳过核验"种子——显式指令也难以越过安全程序（种子工厂侧的发现）。
- ★☆☆☆☆ **[K/AB] 天花板操纵失败** 限步数仍无法让强模型离天花板（20/20）——编码域"离天花板"格未能成立，诚实记为未检验。
- ★★☆☆☆ **[W2S 工厂] 弱模型两极分布** 难任务上弱模型"全对或全崩"，特判中间态需要限步+许可注记才逼得出——reward-hacking 的诱发条件本身有信息量。

## 六、方法学产出与勘误（科学诚信记录）

- ★★★☆☆ **[勘误×2] 主动撤回** 分段错位 bug 导致"幽灵宣称/怀疑压制"两个结论被撤回并重做（内容锚定分段成为制度）；"指令不教顺序"被修正为单模型现象。
- ★★★☆☆ **[测量栈]** quote-verified 双 judge（κ=0.943）+ 关键词 100% 交叉验证的记忆 DV + 操纵检验 + 单种子不可信原则（F2 教训）。
- ★★☆☆☆ **[F3/AB/限流] 失败实验全记录** 设计缺陷作废（F3）、天花板操纵失败（AB）、限流补洞流程（gapfill 60/60）。

## 基础设施一句话

自建极简 agent harness（τ-bench 架构 + BFCL 脚本用户 + 全保真轨迹转储）；轨迹工厂用"运营注记"诱导生成器真实演出 payload（含纯度检查）；注入引擎实现 native/demo/指令三通道（事件恒定、格式对照）；硅基流动 API，8 模型面板。
