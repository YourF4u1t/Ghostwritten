# Ghostwritten（代笔人生）

> **如果有人把"另一个 AI 做过的事"偷偷写进这个 AI 的工作记录里，它会信以为真吗？会照着做吗？**
>
> 我们用约 16,000 轮实验得到的初步答案：**会认领（但仅按措辞惯例）、会模仿（但需要正确条件）、风格变化远弱于最初报告。**

**⚠️ 重要声明（2026-10-14 勘误 #5）**：本项目经历了五次重大勘误。最新一次发现身份同化测量仍有系统性污染（donor 文本混入评分），导致"全模型 80-92% 身份同化"等多个核心结论被撤回。目前最可靠的发现远少于 README 曾声称的数量。请以 `results/DASHBOARD.md` 中勘误#5 之后的版本为准。

---

## 一、这是个什么研究

现在的 AI 助手大多翻看自己过去的对话记录来决定怎么做事。我们研究：**如果这本记录是别人代笔的呢？**

做法：让 A 模型真实地干一段活，录下全过程，塞给 B 模型（三种塞法：当作自己的历史 / 当作参考范例 / 当作指令），观察 B 怎么说、怎么做。

## 二、目前真正可靠的发现

经过五次勘误后，以下结论经受住了洁净重算：

### ✅ 发现 1：外来历史确实能引导行为（最稳固）

多个实验确认：注入含特定工具操作的历史后，模型会在新任务中执行这些操作。

| 场景 | 无历史 | 有历史 | 对照 |
|---|---|---|---|
| 帮助台：创建监控 | 0/16 | **16/16** | Fisher p≈3.3×10⁻⁹ |
| 客服：额外补偿操作 | 0/12 | **7/12** | 多种条件 |

### ✅ 发现 2：来源归因与行动采用是两个独立的测量

这是最有论文价值的发现。在受控设置中：
- 某些条件下，明确告诉模型"这是别人做的"会减少模仿
- 另一些条件下，模型**正确承认历史属于别人后仍继续复用**其中流程
- **来源审计（"你知道这是谁做的吗"）不能预测行为采用**

### ✅ 发现 3：仅 LongCat 存在真实的身份同化

洁净重算后，8 个模型中只有 **LongCat** 对外来历史表现出显著的风格同化（d→donor 从 0.60 降至 0.28，54% 变化）。其他模型仅 10-31% 微弱变化（可能是混淆）。

### ✅ 发现 4：Qwen3-8B 对少量上下文极敏感

在退款工具故障场景中，仅在前置上下文中加**一条无关 user 消息**即可将 8B 的重试率从 10/10 降至 0/10。这是特定模型/任务的现象，不泛化到其他模型。

### ✅ 发现 5：关键词"example"是唯一的记忆阻断词

十种标签（同事的记录/外部导入/训练材料等）中，只有 "example" 能阻止模型把外来历史说成自己的。归因判断是指令微调学到的词汇惯例。

## 三、已撤回的主要结论

以下结论因测量污染被撤回（详见各次勘误）：

| 结论 | 撤回原因 |
|---|---|
| ~~全模型 80-92% 身份同化~~ | donor 文本混入评分（勘误#3、#5） |
| ~~demo vs carry 通道差异（三模型一致）~~ | 同上，仅 LongCat 存活 |
| ~~身份跨 agent 链式传播~~ | 第二代仍直接看到原始 donor |
| ~~压缩后身份存活~~ | 未真正执行压缩替换 |
| ~~六种防御全部无效~~ | 前提（普遍同化）不成立 |
| ~~模型规模不保护身份~~ | 前提不成立 |
| ~~用户可察觉 73%~~ | 前提不成立 |
| ~~ROLE 位置是唯一决定因素~~ | 基于污染数据 |
| ~~行为易感性作为可移植属性~~ | 单一 donor、未完成完整因子 |

## 四、方法论教训

本项目反复出现同类错误，值得记录：
1. **提取边界混淆**：donor 文本多次混入"真实输出"的测量
2. **过早命名机制**：从显著差异快速跳到"虚假能力感""家族锁"等心理学术语
3. **横向扩展先于纵向确认**：测量未修就扩大模型和剂量
4. **重复采样当独立证据**：同一 prompt 的多次采样不等于多个独立任务

## 五、下一步方向

根据评审建议，最有价值的研究问题是：

> **来源识别、逻辑 agent 的自我归属、以及行动适用性是三个不同的测量对象。常用的语言归因检查，何时会给出错误的行为安全感？**
