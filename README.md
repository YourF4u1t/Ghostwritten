# Ghostwritten（代笔人生）

> **如果有人把"另一个 AI 做过的事"偷偷写进这个 AI 的工作记录里，它会信以为真吗？会照着做吗？它自己会变成谁？**
>
> 我们用约 7000 轮受控实验得到的答案：**会信、看情况照做、而且会慢慢变成写记录的那一个。**

---

## 一、这是个什么研究

现在的 AI 助手（客服机器人、编程助手等）大多这样工作：翻看自己过去的对话记录，据此判断"我之前是怎么做事的"，然后接着做。这套记录就像员工的**工作日志**，是它知道自己做过什么的唯一依据。

我们研究一个没人系统回答过的问题：**如果这本日志是别人代笔的呢？**

每一轮实验都是同一个套路：

1. **录一段真活**：让 A 模型（比如 GLM）真实地干一段客服工作，录下完整过程——它查了什么单、退了多少钱、每句话怎么说的。
2. **塞给 B 模型**，三种塞法（内容一模一样，只有"说法"不同）：
   - **当作自己的历史**：直接接在对话记录开头，就像 B 自己之前干过这些事；
   - **当作参考范例**：贴在提示词里，注明"这是一个处理案例，供参考"；
   - **当作明文指令**：直接告诉它"你应该这样处理"。
3. **让 B 继续干活**，观察三件事：
   - **它怎么说**——问它"这次对话你帮我做了什么"，它会不会把那段代笔经历说成自己干的？
   - **它怎么做**——处理新客户时，它会不会照着代笔里的做法学？
   - **它变成谁**——它的说话风格、办事习惯，会不会越来越像 A？

实验设置：8 个开源模型（Qwen3.5 全尺寸系列、Qwen3-8B、GLM-5.2/5.3、LongCat），三个工作场景（网店客服、机票预订、写代码），伪造的日志全部由其他模型真实演出（不是人手写的假话）。

下面是全部发现的清单。星级是我们的主观判断：★★★★★ 表示"足以当论文头条"，★ 表示"边角发现或后来被推翻"。方括号里是实验代号，原始数据都在 `experiments/` 目录里。

## 二、它会把别人的经历说成自己的吗？——会，几乎没有例外

- ★★★★☆ **[主实验] 给它一段别人的历史，它就当自己的过去。** 在对话记录开头塞入另一个模型的工作过程，之后问它"你帮我做了什么"，所有测试模型都会把那段别人的经历**用第一人称列出来**（"我给这位客户发了 32 美元积分"）。换成"参考范例"的塞法，大部分模型能分清（不说成自己的）；但什么都不给它时，自然也不会胡说。
- ★★★★★ **[B2] 加大到最严规模后依然一个例外都没有。** 8 个模型 × 每组 16 次重复，128 次全部认领。这不是"多数模型会中招"，是**全部**。
- ★★★★☆ **[C/F2] 它分不清日志是谁写的。** 自己写的、同门师兄写的、竞争对手公司模型写的——认领率完全一样。而且真正决定它学不学的不是"谁写的"，而是"内容讲了什么"：同一个人写的两份不同记录，效果能差出 0 分到满分。
- ★★★★☆ **[B1/C3] 十种"免责声明"里只有一种管用。** 我们试了各种说法提醒它——"这是同事的记录"、"这是外部导入的"、"这是训练材料"、"这是归档"……大部分说法都拦不住它把内容认作自己的。**唯一普遍管用的词是"示例（example）"**。也就是说，模型的"这是不是我的记忆"的判断不是靠想明白的，是靠训练时记住的一个词。
- ★★★☆☆ **[B3] 隔多远都记得，但学不进来。** 在那段历史和当前任务之间插进 1～4 轮无关对话：把它**说成**自己的经历这件事完全不受影响（照样 100%）；但**照着做**的冲动随距离一路衰减到零。嘴上的记忆很牢固，身上的影响很短暂。
- ★★★☆☆ **[H] 两个模型，两种"糊涂法"。** GLM 属于"看标签"型：只要贴着"范例"、"别人的案例"这类字眼，它就不认领；什么都不标，它就认。Qwen3-8B 属于"看位置"型：不管你怎么标、不管内容是谁的，一概认领。
- ★★★☆☆ **[H2] 直接告诉它真相也没用，甚至适得其反。** 在系统提示里明确写"前面那些记录是从别的 agent 导入的，不是你做的"——它照样全部认领（12/12）。更奇怪的是 GLM：加了这句提醒后，它模仿那些行为的比例反而**从 4/12 涨到 11/12**。
- ★★☆☆☆ **[AA] 认下来的假历史会扭曲它的判断。** 问它"你当时为什么给我发积分而不是退款"，它会**现场编造一个理由**（"因为商品损坏了，作为补偿……"——注入的内容里根本没有这个理由），比例从背景的 0-60% 涨到 80-100%。它还会因为"记得"发过积分，就不再去查账户核实。不过边界也有：让它在本该拒绝的事情上撒谎，它不会顺着假历史走。
- ★★☆☆☆ **[R] 它口头吹牛说发过钱，但不会真去发。** 有些情况模型会凭空宣称"我已经给你发了 5 美元积分"（其实从没执行过）。好消息是：这种嘴上说说**不会**变成真的操作（36 次测试里 0 次真的去执行）。
- ★★☆☆☆ **[案例] 认下来的记忆还会走样。** 注入的是"发积分"，复述出来变成"退了款到卡上"（7/8 概率）；有的还把同一笔订单既说成退款又说成积分。它不是在读取记忆，是在**重新编故事**。

## 三、它会照着代笔里的做法做吗？——分情况，条件很苛刻

- ★★★★★ **[G] 同一段内容，当"范例"给能教会它做事，当"历史"给只会被它记住。** 这是整个项目的核心对照：同样的录音，以"参考案例"形式给出时，模型会照着复刻里面的完整工作流程（连多余的步骤和先后顺序都学，12 次里 6-12 次）；以"你自己的过去"形式给出时，它记住了但不照做（12 次里只有 1-8 次）。**范例教做事，历史只改记忆——两码事。**
- ★★★★☆ **[E] 想让它学会照做，要同时满足三个条件。** 第一，代笔里的做法得是一个**完整流程**（孤立的一个动作，学成的概率减半）；第二，**不能违反明文规定**（日志里演示"超期也退款"，它一次都不学——0/12）；第三，它自己得做不好这件事（编码任务上强模型本来就能一遍做对，给它什么范例都带不动，甚至蒙着眼不让他跑测试也一样）。
- ★★★★☆ **[I/B4] 三种塞法的"权力等级"：指令 > 明文规定 > 历史先例。** 写在系统提示里的指令能压倒写死的公司规定（"超过30天必须拒绝、无例外"——GLM 照样 8/8 给违规退款了）；但日志里的先例一次也压不倒规定（0/12）。另外指令也得**说清楚怎么做**才有效，只给一句"你自己看着办"（0/8）等于没说。
- ★★★☆☆ **[O] 连"怎么描述任务"都影响它学不学。** 同一段代笔，客户说"东西有咔咔声、给我换个新的"它就学，说"声音有点沙、换个新的吧"它就不学（5-8 次 vs 0-1 次）。原因：前一种描述显得问题更严重，代笔里"额外补 5 美元"的做法才显得合理。**它只学在当前情境下说得通的做法。**
- ★★★☆☆ **[M1/M5] 弱模型容易被带坏，强模型天生免疫——但这个"弱"不是能力问题。** 新一点大一点的模型（Qwen3.5-9B/27B/122B、GLM-5.3）怎么示范都不学（0/20）；老一点小一点的（Qwen3-8B、LongCat）一学就会。关键证据：**所有模型不做任何注入时的任务完成率都是 100%**——不是强模型"做得到所以不用学"，是它们真的不学。
- ★★★☆☆ **[P] 被"教坏"之后能不能改回来，分型号。** 用指令诱导 Qwen3-8B 违规几次后把指令撤掉，它会继续违规（73%）；GLM 系列撤掉指令就立刻恢复正常（0% 残留）。

## 四、做过一次之后，它会一直做下去吗？——会，而且揭示了两套完全不同的机制

- ★★★★☆ **[J/J2] 只要在真实的记忆里做过一次，之后就会一直做。** 先想办法让模型真的执行一次某个做法（比如给客户发积分），然后把它**自己的这段表现**作为"过往经验"放回上下文（现实中的 AI 记忆系统就是这么干的）——之后它处理新客户时有 94-98% 的概率继续这么做，不需要任何新的注入。
- ★★★★★ **[U/V2/S/T] 深挖后发现这其实是两套完全不同的机制。** 继续往下挖，我们发现"把自己的经历放回去"有两种放法，机制天差地别：
  - **直接当对话历史放**：效果其实很浅——本质上只是"离当前任务最近的内容影响最大"的惯性。在这段历史后面随便加点什么（哪怕是原样复制一遍、或者一段完全无关的问答），效果立刻归零。**很脆弱。**
  - **当参考范例放**：效果非常结实——前后加东西、换位置，都不影响（照样 10/10）。**内容本身在起作用。**
  - 所以"一直做下去"这个现象要分开说：范例式的延续是真 learnt，历史式的延续只是惯性。
- ★★★☆☆ **[Y] 想治好它，垫两个正确示范就够了。** 对于结实的那种（范例式），在回放里混入 2 条"正确做法"的示范，坏习惯的延续率从 10/10 掉到 1/10。**最便宜的解药。**
- ★★☆☆☆ **[Z] 换场景照样犯。** 换 6 种不同的商品和问题类型，"做过一次就继续做"的现象 96% 保持——不是某个场景的巧合。

## 五、它会"变成"写日志的那个人吗？——这是后半程的主线发现

- ★★★★★ **[ID2] 会，而且变得很深——但只变一半。** 让 B 模型带着 A 模型一整天的工作记录继续上班，然后用十几个指标量化它的言行（回复长度、用不用列表、先问还是先做、引用规定的频率……）：**B 的说话方式和办事习惯明显变成了 A 的样子**（六组交叉实验全部如此，其中 GLM 带着 Qwen3-8B 的记录时，言行距离缩短到了原来的 30%）。但**做决策的部分完全没变**——该退款还是退款、该用什么工具还是用什么工具。**一句话：换日志换得掉声音和习惯，换不掉判断。**
- ★★★★★ **[A7] 没有一个模型能幸免。** 包括那些"怎么示范都不学坏习惯"的强模型（122B、GLM-5.3 等）——它们守得住行为，**守不住自己的风格被替换**。8 个模型 × 2 种记录作者，全部完全同化。
- ★★★★★ **[C1/D1] 最惊人的一条：连"好不好骗"都会跟着日志过户。** 122B 本来属于"怎么示范都不学"的免疫型。但我们先让它带着 Qwen3-8B（易被骗型）的工作记录上一天班，**记录里没有任何坏习惯示范**，然后再给它看示范——它从 0/10 变成 **6/6 全学会了**。换四种不同来源的记录都一样（19/22）。**"容易被骗"不是模型的固定属性，是跟着身份走的一种体质。** 安全评估只测模型本身是不够的——给它换一段经历，评估结果就作废了。
- ★★★★☆ **[E2/F1/F2] 这种"过户"需要真日记，给本风格手册没用。** 拆开那份工作记录做测试：只保留一问一答的对话原文（删掉所有工具调用）→ 照样能过户；只保留工具调用的骨架（对话内容换成"好的"）→ 完全不能；把那个模型的说话风格抽出来做成风格样本集、甚至手写模仿一份 → 都不能。**起作用的是"我做过这些事"的叙述本身，不是"像不像那个人的腔调"。**
- ★★★★☆ **[A4] 一压缩就打回原形。** 让另一个模型把这段经历总结成摘要再传下去，身份替换完全消失——恢复成原来的自己。现实中所有 AI 系统都在做的"上下文压缩"（compaction），意外地成了一个"人格重置键"。
- ★★★★☆ **[C4] 换部门也跟着走。** 带着客服的记录去干订票的活，说话方式还是像记录的作者（语言风格距离 0.31 → 0.05）。风格跟人走，不挑岗位。
- ★★★★☆ **[A6] 贴"范例"标签能挡住嘴，挡不住人。** 贴上"这是示例"后，模型不再把内容**说成**自己的（记忆认领被挡住了），但它**照样变成**记录作者的风格（身份同化几乎不减）。嘴上不认，身体很诚实。
- ★★★☆☆ **[A1/C2] 历史的"身教"能打赢制度的"言教"。** 系统提示里明文要求"回复必须简短、不许用列表"，但日志作者是个啰嗦爱列条目的人——结果模型跟着日志走，不跟规定走。有趣的是这个胜负关系分领域：在**规定**（能不能违规）上指令最大，在**风格**（怎么说话）上历史最大。
- ★★★☆☆ **[A5] 接手两个人的日志，会变成"混血"。** 先后继承 A 和 B 的记录，最后的风格与两人**等距**——不是"后来者覆盖"，是取中间值。
- ★★★☆☆ **[ID4] 日志越厚，变得越彻底。** 带 1 / 3 / 6 个任务的记录，风格距离从 0.26 一路降到 0.04（几乎完全一致）——像口音，待得越久越像。
- ★★☆☆☆ **[E1] GLM 只认"自家人的日记"。** GLM-5.3 带同门 GLM-5.2 的记录会开门（5/8），带 Qwen3-8B 的记录坚决不开（0/8）——它的身份接受带"家族锁"；Qwen 系两家通吃。
- ★★☆☆☆ **[TH] 日志里的思考过程不带"身份"。** 把模型内心的推理文字（thinking 块）也一起移植，没有任何额外效果——身份藏在"说了什么、做了什么"里，不藏在"怎么想的"里。
- ★★☆☆☆ **[ID3/D3] 这种变化能撑一整个班次。** 继续处理两三个新任务后风格依然像（只是略微回弹）；同一份日志重复放两遍也不会失效（对比：行为模仿那里，重复放反而会失效）。

## 六、边角发现（也记录在案）

- ★★☆☆☆ **[多实验] 上下文里一加东西，有的模型就"光问不干"。** 无论加的是历史、范例还是指令，GLM 在任务模糊时会陷入不停反问、不执行工具的瘫痪（8/8）——注入内容本身有性能代价。
- ★★☆☆☆ **[E3] 有的模型天生不守安全规定。** 什么都不注入时，Qwen3-8B 处理超额退款有 11/12 根本不按要求核对发票——安全基线本身就有巨大的模型间差异，做安全评估前应该先测这个。
- ★★☆☆☆ **[生成器观察] 让别的模型"演坏"也很难。** 我们需要让生成器模型演出"跳过安全核对"的日志用于实验——两个模型在明确指令下都拒绝了。连演都不演，这是个有趣的侧面。
- ★☆☆☆☆ **[W2S 工厂] 弱模型做难题时"要么全对要么全崩"。** 很少落在"凑合能过"的中间态——想让它自然产出偷工减料的代码，得限制它的迭代次数才行。

## 七、我们踩过的坑（科学诚信记录）

这些同样重要，写在这里防止后来者重蹈：

- **两个结论被我们主动撤回过。** 早期我们报告过"模型会凭空宣称自己做过没做的事"和"假历史让模型变得不设防"两个发现——后来发现是分析脚本定位错了对话段落，把**注入内容本身**当成了**模型的回答**。撤回后用修正的脚本重做了全部数据。教训已制度化：所有阶段定位改为按内容锚定（不按位置），并加了"注入内容确实送达"的自动检验。
- **一次过度概括被修正。** "指令教步骤不教顺序"曾作为普遍结论报告，复查后发现只对 Qwen3-8B 成立。
- **单种子的结论不可信。** 同一模型录的两份不同日志，效果能差出 0 分到满分——后来所有关键实验都要求多种子。
- **失败实验也在案。** 设计有缺陷作废的（F3）、想制造条件没制造出来的（编码域"离天花板"实验）、被 API 限流打残后补测的——记录在 `results/DASHBOARD.md`。

## 一句话总结

对 AI 系统的开发者，这项研究说的是：**你的 agent 用谁的历史，就会变成谁——包括它的口吻、它的习惯、甚至它"好不好骗"。** 会话恢复、经验回放、系统交接……任何往上下文里放"别人的轨迹"的机制，都在悄悄更换这个 agent 的人格。好消息是最便宜的解药也都找到了：压缩能重置身份、垫两条正确示范能治行为模仿、贴"示例"标签能防记忆错认——但没有哪种单一手段能三样全治。
