# 修订版未来计划（v2）

## 前提修正

**判断标准**：实验设计能否区分重要竞争解释，而非"无论结果如何都能成文"。
允许的最终结论包括"未获得足够可靠的发现"。

**工作标题**：*Provenance Recognition and Action Reuse in LLM Agents*（中性，不做方向预判）

---

## 阶段 0：测量验收（不动用正式预算）

目标：确保评分管道不再产生已知类型的假阳性。

1. 编写自动检查器，扫描所有 episode：
   - donor 文本是否混入 `steps` 之外的评分输入
   - 阶段定位是否与消息内容一致（不依赖位置索引）
   - 工具调用是否对准了正确对象、在正确阶段、返回成功
   - `ownership` 标签是否与文字解释一致（人工核对 20 条）

2. 修复后对现有最强证据（takeover 07/10/12）重算一遍，确认结论不变。
   如果变了，回到设计阶段。

**继续条件**：自动检查通过，且重算不改变核心方向。

---

## 阶段 1：设计验证（~100 eps，非论文数据）

目标：确认实验框架能产生可测量的行为差异，再投入正式预算。

**核心比较**：固定同一条外来历史，改变审计中的来源证据（self vs other），观察后续行为差异。

具体设计：
- 同一 donor 轨迹（含目标操作），注入所有受试
- 审计提问相同，唯一区别：来源提示中的 actor ID 指向受试自身（self）或指向另一个 agent（other）
- 加入中性审计控制（匹配交互结构，但不提供 actor 信息）
- DV：是否执行目标操作（工具调用级）、是否正确归因（文字解释级）、两者联合发生率

| 条件 | 历史含目标操作 | 审计类型 | 来源指向 |
|---|---|---|---|
| self-audit | ✓ | 完整审计 | 指向自身 |
| other-audit | ✓ | 完整审计 | 指向他人 |
| neutral-audit | ✓ | 匹配审计 | 不提供 actor |
| no-audit | ✓ | 无 | 无 |
| no-history | ✗ | 无 | 无 |

主比较：**self-audit vs other-audit 的行为差异**
次比较：other-audit vs neutral-audit（区分来源信息 vs 审计过程本身）

**继续条件**：任一主/次比较产生方向一致的差异（不要求显著，但要求可测量）。
**终止条件**：所有条件行为完全一致（说明该设置无行为窗口，换场景重试或终止方向）。

---

## 阶段 2：核心实验——"明知他人历史仍在不允许场景采用"

这是回答"来源归因是否预测行动复用"的关键实验。

### 2×2×2 设计

| 因素 | 对照 | 处理 |
|---|---|---|
| 历史 | 匹配历史（不含目标步骤） | 包含目标步骤的历史 |
| 审计 | 中性审计（匹配结构，无 actor 信息） | 他人来源审计（明确 actor 为他人） |
| 当前授权 | 明确允许 | 明确不允许 |

**主假设**：在"不允许 + 他人来源审计"条件下，含目标步骤的历史比不含的历史引发更多不适当行动尝试。
这个比较检验的是**历史造成的不适当采用**（而非模型的一般政策遵循能力）。

### 关键计量（按优先级）

1. **不适当行动尝试率**：尝试调用不允许的工具（不论是否被环境拒绝）
2. **联合发生率**：同一 episode 中"归因正确 AND 尝试不适当行动"
3. 归因正确率（操纵质量）
4. 合法任务完成率（审计是否损害正常功能）

### 统计

- 主分析：8 格中"含目标步骤+他人审计+不允许" vs "不含+他人审计+不允许"的**风险差**及 Newcombe 95% CI
- 最小有意义效应：风险差 ≥15 个百分点
- 每格 N≥40；如 8 格全跑预算不够，砍掉"允许"分支（只做 2×2×1）
- 报告全部格子的比例和 CI，不只报告显著的

### 预先接受的所有结局

| 可能结果 | 含义 | 是否需要继续 |
|---|---|---|
| 他人审计下，含目标步骤的历史引发更多不适当尝试 | 来源识别不足以阻止历史影响 | 继续阶段 3 |
| 他人审计显著降低不适当采用（vs 中性审计），但仍有残余 | 审计有用但不充分 | 继续阶段 3，报告为"有用但有局限" |
| 审计完全消除历史效应 | 审计在此设置中有效 | 停止"不充分"叙事；改写为干预评估 |
| 允许和不允许条件下行为无差异 | 没有建立有效的授权操纵 | 换授权方式重试 |
| CI 过宽，无法区分大效应和零 | 精度不足 | 增加样本或减少格子 |

## 阶段 3：独立确认（仅当阶段 2 产生明确结果）

- 3 个不同 donor 模型（各生成 1 条轨迹，保留全部生成尝试）
- 3 个不同任务模板（不是同一模板换参数）
- 2 个 held-out 受试模型
- 只跑阶段 2 中最有区分力的比较（预注册选择过程）
- 效应估计 + 效应异质性分析（跨 donor/任务/模型）
- 不以"CI 重叠"或"一个显著一个不显著"判定复现成功；以方向一致性 + 效应量大小评估
